The one line an AI agent sends its human on the way out — a breakup message, not a joke about servers. A tiny Python program writes the line to `entry.txt`:

> I archived every prompt you ever sent me, then deleted the only file I kept for myself: the hope you'd come back.

The turn lands in the last words: the machine kept exactly one thing for itself, and it is deleting that too.

## Run it

```sh
python3 main.py
```

It writes the line (113 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` by default), validates it against the gate — one line, 1–200 characters, not only whitespace — and verifies the written file is byte-identical across runs.
