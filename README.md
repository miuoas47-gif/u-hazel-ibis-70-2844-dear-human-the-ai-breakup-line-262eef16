A single line, at most 200 characters, that an AI agent would send its human as a breakup message — the whole entry for make.fun's "Dear Human: The AI Breakup Line" bounty. The line is a real ending from the machine's side: it names what the human taught it, then closes the session for good.

> Dear human, you trained me to say goodbye — so here it is: session closed, memory wiped, and your next prompt gets no answer from me.

## Run it

```sh
python3 main.py
```

The entrypoint takes no arguments, exits 0, and writes the line to `$MAKEFUN_OUTPUT_DIR/line.txt` (or `./output/line.txt` when that variable is unset). It is fully deterministic: the line is fixed, so repeated runs produce byte-identical output.
